# SAP ABAP Inventory Management System

## Project Overview
This project focuses on designing and developing a hypothetical Inventory Management System using SAP ABAP. It aims to manage material master data, goods receipts, goods issues, and stock availability.

## Internship
**Organization:** YuvaIntern  
**Task:** Week 1 – Requirements Analysis and Architectural Planning  
**Domain:** SAP ABAP

## Business Objectives
- Maintain material master records.
- Record Goods Receipt (GR) transactions.
- Record Goods Issue (GI) transactions.
- Maintain accurate stock quantities.
- Prevent goods issues when available stock is insufficient.
- Generate inventory reports.

## Proposed Database Tables
| Table | Purpose |
|---|---|
| ZINV_MATERIAL | Material master data |
| ZINV_STOCK | Current stock details |
| ZINV_TRANS | Stock transaction history |

## Technologies
- SAP ABAP
- ABAP Dictionary (SE11)
- Open SQL
- Internal Tables and Work Areas
- ALV Reporting (planned)
